Apps:
- Customer: /index.html
- Admin: /admin.html
- Billing: /billing.html
- Rider: /rider.html

- Admin shop approval, store commission, rider control, salary/incentive/penalty, khata, settlement, notification, AI parcha scan hooks
- Customer product Excel master, wholesale/retail/both, cart, khata, order tracking, cancellation
